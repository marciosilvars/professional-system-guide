# BETAXLOG — Sistema Profissional de Escalas

## Tarefas
- [ ] Banco de dados na nuvem (motoristas, escalas, itens, papéis, auditoria)
- [ ] Autenticação (e-mail/senha + Google) com admin e supervisor
- [ ] Design system corporativo azul-marinho
- [ ] Tela operacional: configuração de vagas, geração automática com rodízio, prévia/definitiva
- [ ] Gestão de motoristas (CRUD, busca, prioritário, indisponível do dia)
- [ ] Status de rota por item (escalado/concluído/cancelado)
- [ ] Compartilhamento: imagem, texto WhatsApp, Excel do dia
- [ ] Relatórios: KPIs, gráficos, ranking, export Excel/PDF
- [ ] Histórico auditável (log de ações)
- [ ] Metadados SEO por rota
